# 画面、事件与状态设计

## 画面与操作

- 顶栏：WQ DAY 美东日期、距下次重置的倒计时、当前挖掘会话数、完成批次、候选目标与 LIVE / DEMO / REPLAY 标记。LIVE 使用本地时钟；DEMO 从快照 `generated_at` 推算演示时间并继续走秒，重复快照不会让时钟倒退。SSE 断开时显示 RECONNECTING，浏览器会自动重连。
- 八张角色卡：生成、预检、回测、评估、相关性、候选、错误和复核；进度、主数字和消息来自后端快照。预检消息反映最近一次预检或提交的结果，累计失败数仍保留。评估卡的数值是当天累计通过数，消息用「最近一批无通过」或「最近：alpha Sharpe x」说明最近一批，未有评估时显示「暂无评估」。
- 交易大厅：最多六个工位，对应快照会话的形状、颜色与阶段；超出数量显示在最后一个工位。没有 pid 的旧日志显示为「未知会话」。后墙蛛网的中心为 (595,153)，半径为 x 221、y 60；场景 viewBox 为 `0 35 1200 600`。蛛网用 16 根辐射丝和 6 圈螺旋丝承载最近 60 个 alpha 茧，机械蜘蛛在上面抓取、分拣；左下方的 WQ BRAIN · SIM 机柜显示当前回测批数。右侧是相关性雷达、合格最佳 alpha 的火箭和候选复核台，左下碎纸机显示淘汰合计。
- TODAY · OUTPUT：只显示每 15 分钟完成的回测批次柱状图。已观察到回测失败的桶显示红柱，并保留到 WQ 换日；首次加载时后端只提供最近 60 个事件，因此不能恢复全部历史失败柱。
- ALPHA ANALYSIS：Sharpe × Fitness 散点与两档评估阈值。只过滤未通过且超出 P2–P98 扩展范围的异常点，合格 alpha 保留；图上显示忽略数，详情和累计数不受影响。散点最多显示 1500 个，超出时优先显示候选及其他合格点。

点击蛛网中的茧、散点、候选便签或 TOP RUNNER 可打开详情抽屉。抽屉显示表达式、S/F/T、状态、失败项、Prod、会话、simulation id 和时间；支持复制表达式、Esc 关闭和点击遮罩关闭。采集日志中的表达式每条最多 4000 字，超出单行字节预算时会缩至 120 字，必要时再裁剪记录；抽屉展示已有文本，候选可由本地台账补齐，不会从 WQ 平台补取完整表达式。悬停工位可查看该会话的统计。

宽屏是八卡一行，左侧大厅占约 72% 宽度；右侧上方是约 220px 的 OUTPUT，下方分析面板占剩余高度。1920×1080 一屏显示，没有纵向滚动。900–1439px 大厅通栏，OUTPUT 与分析面板并排；小于 900px 为单列。手机场景保留至少 820px 宽度，仅在场景内横向滑动，页面没有横向滚动。

输出与散点通过 ResizeObserver 使用实际像素尺寸绘制，字号固定 10px。抽屉、更新时间和含时间的提示统一为本地 `MM-DD HH:mm:ss`；图表时间轴保留简短的 `HH:mm`。场景角色与前景标牌分层，空工位在有会话时关屏。

页面遵循系统「减少动态效果」设置；隐藏标签页时暂停动画，也不回放期间错过的历史事件。

页面先请求 `/api/state`，再连接 SSE。既有节点按 id 更新，网络、列表、散点和飞行动画都有数量上限；首次连接和跨日不会回放已有事件。

## 蜘蛛与事件过程

### 调用进行中

被采集的工具在执行前写 `ph:"start"`，执行结束后写 `ph:"end"`。开始行只含身份和参数标识，不代表回测或检查已成功；每日计数、指标与候选仍由结束行更新。旧日志没有 `ph` 时按结束行读取。仪表盘兼容原有日志；修改装饰器后需重启工具进程。

会话优先显示当前进行中的调用：提交中、预检中、等回测、评估中、查相关性、存候选。没有进行中的调用、最近 15 分钟仍有活动时显示「构思中」；这只是两次工具调用之间的状态，不推断 AI 的具体思考内容。超过 40 分钟的未结束调用会清除；进程退出时也会清除并释放工位。

进行中的画面由同一个低频时钟驱动：显示器、机柜灯、便签笔画和角色双手最多每秒更新一次。评估时蜘蛛每 3.5 秒检查下一个茧；查相关性时雷达朝目标每 3 秒发一次脉冲；存候选时先展示正在写的临时便签，结束后才翻出正式便签。开始事件立即显示 agent 名称、批次条数或 alpha id。没有新事件的工作空档里，蜘蛛每次休息 20–30 秒后沿丝短程往返，移动仍由原有缓动和限位控制，腿部更新上限由 `web/animation-rules.js` 的 `SPIDER_LEG_HZ` 控制。

配置回测进度注册表（可选）后，服务每 5 秒只读该文件，按 sim id 关联等待批次；机柜每批八格灯、工位进度和字幕优先使用注册表的真实进度。`children_done` 按注册表进度乘以子任务总数向下取整：写入方只提供子任务 URL，未提供逐项完成标志。缺少或损坏的注册表不影响日志读取；没有真实进度时，退回最近 20 次等待时长的中位数估算，最多显示 95%，不会据此宣布完成。

演示同样生成配对的开始/结束行，并在演示临时根目录写自己的 `multi_simulation_progress.json`；不写外部数据源或真实日志目录。隐藏页面、减少动态效果或所有会话均空闲时，工作时钟和巡逻停止。事件后的 15 秒环境动画窗口、60 秒全面空闲暂停与原有事件叙事保持独立，环境停止不会取消正在播放的结果动画。

### 结果事件

机械蜘蛛有分段金属腹部、头胸部、四只发光眼睛和八条三段机械腿。待机用 CSS 轻微呼吸和抖腿；工作时沿辐射丝爬行，前腿伸到小球的实际位置。触点重合后小球随腿尖收回，再落到网格交点成为茧。角色保持坐姿，不新增行走、情绪或拖动交互。

| 事件 | 画面过程 |
| --- | --- |
| 提交回测 | 工位纸条按 80ms 间隔飞入机柜，每批最多画 8 张，印出简短表达式 |
| 预检或提交失败 | 纸条到机柜门口弹回，掉进碎纸机并吐出纸屑 |
| 回测完成 | 机柜吐出光球，蜘蛛到蛛网边缘逐个抓取，变成可点击的茧 |
| 回测失败 | 冒烟纸团从机柜落入碎纸机 |
| 评估通过或失败 | 蜘蛛碰触对应茧，弹入 PASS 或 REJECT 丝，滑到末端后更新计数 |
| 相关性检查 | 雷达用光束连接对应茧并发出脉冲；拦截时变红，再送入淘汰丝 |
| 存为候选 | 茧沿复核丝越过屏幕边框，落到对应便签位置，便签翻出 alpha id 和 Sharpe |
| 本地拒绝 | 茧沿淘汰丝滑落 |

蜘蛛一次处理一个动作，纸条和机柜可并行。串行动作超过 12 项时，积压合并为一次短动作，茧、便签和计数立即跳到快照最终状态。底部字幕与动作同步，保留最近三条滚动淡入淡出。动画没有工作时停止 requestAnimationFrame；隐藏页面会清空队列并同步最终状态，回来不补播；系统减少动态效果时直接展示状态。没有数据时，蜘蛛仍在网中央待机，屏幕显示 WAITING FOR MINERS。

## API 与状态

- `GET /api/state`：当前快照，`mode` 是 `live`、`demo` 或 `replay`。
- `GET /api/stream`：SSE。连接后立即发送 `event: state`，之后有状态变化时发送，频率不超过每秒一次；每 15 秒有注释心跳。
- `GET /` 及静态文件：来自 `web/`，不允许访问目录外的文件或符号链接目标。

所有响应带 `X-Content-Type-Options: nosniff`，API 带 `Cache-Control: no-store`。HTML 响应包含 CSP，脚本和连接只允许同源。快照按 revision 缓存，后台读取与请求共享状态锁。会话变为空闲、卡片忙碌窗口结束和时间线进入新桶，也会更新 revision。

快照固定包含八张卡片：生成、预检、回测、评估、相关性、候选、错误、复核。还包含按终端分组的会话、alpha 明细、等待中的回测、漏斗、拒绝原因、15 分钟时间线、合格最佳 alpha、待复核候选和最近事件。前端可用事件的单调 seq 触发动画。

事件保持原有字段，并按类型附带 `sim`、`n`、`alphas`（最多 8 个 id）与 `exprs`（提交事件，最多 8 条、每条前 24 字）。这些字段来自摘要的状态聚合，不改变采集日志。旧日志生成的事件或缺少可选字段的快照仍可展示。

同一 alpha 的回测、评估、Prod、本地保存按阶段推进；延迟到达的早期结果不会把候选或相关性状态退回。表达式通过哈希回填；没有文本时 `expr` 是 null，可显示 alpha id。日志优先用 ppid 识别终端，缺少时用 pid，两者都缺少时归到「未知会话」。快照的 pid 是这个会话关联键，validator_pid 保留验证器进程号。工牌显示 agent 名称（ccs profile、codex 或 claude），同名终端按首次出现顺序编号；无法识别时显示「终端 N」。存活终端 15 分钟没有调用时显示为空闲。

配置候选台账（可选）后，面板每 5 秒只读这些文件，按 alpha id 为候选及其快照明细补齐完整表达式；同一 id 取后出现的有效记录。缺失或不可读的台账及坏行会忽略，demo 模式始终不读取外部台账。

正式模式每 10 秒检查父进程（旧日志则检查验证器进程），已退出会话释放工位，累计统计保留，页脚显示「今日已结束 N」。缺少 agent 的存活旧进程会补查并缓存名称，无需重连 MCP；没有进程身份的「未知会话」超过 30 分钟隐藏。演示和历史回放不检查本机进程。旧记录没有 ppid 且验证器已经退出时，无法再追溯原终端名称，仍保留历史累计计数。

TOP RUNNER、分析统计和时间线的最佳 Sharpe 只取评估通过、未被相关性拦截或本地拒绝的 alpha（eval_passed、prod_ok、candidate）。后续拦截或拒绝会移除其最佳资格；没有合格 alpha 时显示「暂无合格 alpha」和「—」。散点只做上述显示过滤，原始 alpha 详情不受影响。

快照通常最多包含 1500 个 alpha；候选全部保留，因此候选本身超过 1500 时可突破这个上限。内存中的非候选明细、回测记录和表达式缓存会裁剪，每日累计计数继续保留。最近事件最多 60 条；时间线通常为 96 桶，美东换季当天为 92 或 100 桶。

被裁剪记录的去重信息暂存在标准库 SQLite 临时数据库中，页缓存限制为 256 KiB；数据库关闭时自动删除。这样重复读取旧回测不会增加每日总数，也不需要让全部历史明细常驻内存。快照中的会话和等待回测列表会合并临时索引中的记录，缓存裁剪不会减少活跃数或等待数。跨日时释放旧索引，原始 JSONL 不受影响。美东午夜到达时立即切换 WQ 窗口，重新扫描覆盖文件，旧窗口中的残缺行不会阻塞切换。

阈值只来自配置中的展示阈值对象；缺失或无效时，快照的 `thresholds` 为 null。阈值不改写采集结果或平台判定。
